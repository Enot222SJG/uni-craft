# 🎮 Uni-Craft

> **Играй в Minecraft на школьных киосках и компьютерах с MOS Linux!**  
> *На других системах не проверялось, но должно работать везде, где есть Flatpak.*

✅ **Все действия выполняются без прав root!**

---

## 📦 Что вам потребуется

### Для киосков (обязательно)
- Беспроводная клавиатура и мышь (или клавиатура с тачпадом)  
  *На сенсорном экране играть практически невозможно.*

### Для всех случаев
- Флешка **от 8 ГБ** (для переноса скрипта и установочных файлов)
- Хорошие друзья, которые **постоят на шухере** 😏

---

## 🚀 Установка

### Способ 1: Автоматический (через скрипт)

1. **Скачайте скрипт** `uncri.sh` и положите его на флешку, а затем в любую папку на целевом ПК.
2. **Откройте терминал** в папке со скриптом:
   - ПКМ по пустому месту → `Открыть Терминал в этой папке`
3. **Сделайте скрипт исполняемым:**
   ```bash
   chmod +x uncri.sh
   ```
4. **Запустите скрипт:**
   ```bash
   ./uncri.sh
   ```
5. **Выберите тип устройства:**
   ```
   1. kiosk
   2. pc
   > 1/2
   ```
6. **Ждите окончания установки.**

---

### Способ 2: Ручная установка (без скрипта)

#### Этап 1: Скачивание лаунчера
1. Скачай **TL Legacy** для Linux:
   - Найди в поиске *"скачать tllegacy линукс flatpakref"*
   - Или перейди на [Flathub.org](https://flathub.org) и найди **TL Legacy** там
   - Скачай файл с расширением `.flatpakref`

#### Этап 2: Установка
1. Перемести скачанный файл в удобную папку на целевом ПК.
2. Открой **терминал** в этой папке (ПКМ → `Открыть Терминал в этой папке`).
3. Выполни установку (замени `имя_файла.flatpakref` на актуальное название):
   ```bash
   flatpak install --user имя_файла.flatpakref -y
   ```
4. **Важно для игры без лицензии:**  
   Введи эту команду, чтобы лаунчер работал в офлайн-режиме:
   ```bash
   flatpak --user override ch.tlaun.TL --env=TL_BOOTSTRAP_OPTIONS="-Dtl.useForce"
   ```

#### Этап 3: Запуск игры

Есть три способа запустить лаунчер:

- **Через терминал:**
  ```bash
  flatpak run ch.tlaun.TL
  ```
- **Если терминал недоступен** (киоск-режим):  
  Нажми `ALT + F2` и введи:
  ```
  flatpak run ch.tlaun.TL
  ```
- **Через меню приложений:**  
  Найди **Legacy Launcher** в списке программ.
