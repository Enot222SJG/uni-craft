# uni-craft
Да да, с помощью этого вы сможете играть в майнкрафт на киосках/школьных пк на MOS линуксе!!! На других системах не проверялось.

                                  !!Все действия выполняются без root прав!!
Вам потребуется:

//В случае с киоском (дополнение)
1. Беспроводная клавиатура и мышь (или клавиатура с тачпадом)

//В обоих случаях
2. Флешка, не мешьше 8 гигов
3. Иметь хороших друзей, которые смогу постоять на шухере, пока ты будешь делать грязь

Для того, что бы играть в майнкрафт на школьных киосках(или пк на информатике) вам потребуется:

//В случае с киоском (дополнение)
1. Беспроводная клавиатура и мышь (или клавиатура с тачпадом)

//В обоих случаях
2. Флешка, не мешьше 8 гигов
3. Иметь хороших друзей, которые смогу постоять на шухере, пока ты будешь делать грязь

--Случай со скриптом

1. Открываем терминал в той же папке где и скрипт
	-> ПКМ по пустому месту в папке
	-> Открыть Терминал в этой паке
	Пишем: chmod +x uncri.sh
	
2. Запускаем скрипт (или в терминале ./uncri.sh)

3. Выбираем на что мы хотим установить:
	1. kiosk
	2. pc
	> 1/2
	
4. Ожидаем окончания установки..

--Случай без скрипта
	А теперь приступим к пошаговой установке:
		1. Скачиваем установочный файл TL Legacy 
			(вбить в поиск "скачать tllegacy линукс"
			зайти на сайт FlatHub и скачать файл .flatpakref)
														 
		2. Зайти в папку с файлом, который мы только что скачали
		(или взять из архива)
		
		3. -> ПКМ по пустому месту в папке
		   -> Открыть Терминал в этой паке
		   
	//Ура! Мы закончили с 1 этапом установки!

		4. Вписываем в терминал команды
		  - flatpak install --user *имя файла* -y
			//После установки, если потребуется играть без лицензии
		  - flatpak --user override ch.tlaun.TL --env=TL_BOOTSTRAP_OPTIONS="-Dtl.useForce"
		
	//Ура! Теперь мы завершили 2 этап установки! Почти всё готово!

		5. Для запуска есть 3 варианта
		  - CTRL + ALT + T >> flatpak run ch.tlaun.TL
		  - ALT + F2 >> flatpak run ch.tlaun.TL (если не работает терминал)
		  -	В пуске пишем в поиске Legacy Launcher
		  
	Всё! Мы завершили установку!
